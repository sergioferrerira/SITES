# Camazo Barbershop · Aveiro

Site de uma página, sem dependências: galeria, menu de serviços com preços e marcação por WhatsApp.

- Serviços, preços, horário e galeria estão no bloco `DADOS` no início do `<script>` em `index.html`.
- O pedido de marcação abre o WhatsApp do número `TELEFONE` com a mensagem já preenchida.
- Fotos em `img/`. Para juntar fotos de cortes, adiciona-as ao array `GALERIA`.
